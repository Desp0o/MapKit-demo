# MapKit Playground

Exploring MapKit to test its features and capabilities.

In this test project, I experimented with how to:

- place markers and custom annotations  
- show user location  
- search for nearby places  
- view place details and Look Around previews  
- get directions to a selected location  

## Features

- 📍 Place marker  
- 🧷 Add custom annotation  
- 📍 Show user location indicator  
- 🔍 Search nearby places  
- 📝 Display details of a selected place  
- 👁️ Preview Look Around for selected place  
- 🧭 Get directions to destination
